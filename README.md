\# Gestion Bancaire en Java



\## 📌 Description



Projet académique réalisé en Java portant sur la conception d'une application de gestion bancaire.



L'application permet de modéliser les principaux éléments d'un système bancaire et de réaliser des opérations simples sur les comptes clients.



\## 🎯 Objectifs



\- Modéliser des clients et leurs informations

\- Gérer les comptes bancaires

\- Enregistrer les clients auprès d'une banque

\- Effectuer des opérations de retrait

\- Consulter le solde d'un compte

\- Conserver un historique des dernières opérations



\## 🛠️ Technologies



\- Java 21

\- Programmation orientée objet (POO)



\## 📂 Structure du projet



\- `Adresse.java` : gestion de l'adresse d'un client

\- `Personne.java` : représentation d'un client

\- `Date.java` : représentation d'une date

\- `CompteClient.java` : gestion du compte et des opérations

\- `Banque.java` : gestion des clients et des comptes

\- `Distributeur.java` : gestion des opérations de retrait

\- `GestionBancaire.java` : classe principale permettant d'exécuter l'application
